# Quick Guide - Get This Project (2 minutes)

You do not need a GitHub account to download this course. If you already have the folder, skip to [START-HERE.md](START-HERE.md).

> In one sentence: **GitHub** is a website where project files can live. You are downloading a folder from it, like downloading a PDF.

## Download the course

1. Open [github.com/euroconic/codex-bootcamp](https://github.com/euroconic/codex-bootcamp) in your browser.
2. Click the green **Code** button.
3. Click **Download ZIP**.
4. Find the download and unzip it:
   - **Mac:** double-click the zip file.
   - **Windows:** right-click it, choose **Extract All**, then click **Extract**.
5. Move the unpacked folder somewhere easy to find.

Open the folder and confirm that it contains `START-HERE.md`, `AGENTS.md`, and `missions/`. Then continue with [START-HERE.md](START-HERE.md).

## Optional: make your own GitHub repository

If you have a GitHub account, use **Use this template** on the course repository instead of downloading the zip. Give your copy a name, create it, and then clone or download your copy. This gives you a place to publish the commits you make in Mission 09.

If those words are unfamiliar, use the zip route. Your mentor can explain GitHub when you reach Mission 09.
