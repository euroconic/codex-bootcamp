## How to get on the board

The public showcase URL is not set yet. Before publishing the course, replace:

`REPLACE_WITH_CODEX_BOOTCAMP_SHOWCASE_URL`

Once it is available:

1. Open `SHOWCASE.md` in the public repository.
2. Click the pencil icon.
3. Add one row to the table below.
4. Click **Commit changes**, then **Propose changes**.
5. GitHub creates a pull request. When it is merged, you are on the board.

Prefer help? Ask your mentor: "help me open a pull request to add me to the bootcamp showcase." Codex can guide the browser route or use the `gh` tool if it is installed and you approve the external action.
